# DL_Beginner-problem_in_perceptron-
Perceptron_problem = cannot solve not linearly seperable data(ex: xor)

Perceptron Algorithm

This project demonstrates the implementation of the Perceptron Algorithm for binary classification using logical gate datasets such as AND, OR, and XOR.

Technologies Used
Python
NumPy
Pandas
Matplotlib
Seaborn
Scikit-learn
Mlxtend

Features
Perceptron model training
Prediction and classification
Scatter plot visualization
Decision boundary plotting
AND, OR, XOR gate implementation

Key Learning
Binary Classification
Neural Network Basics
Linear Separability
Decision Regions


Limitation:
Perceptron works only for linearly separable data and cannot solve the XOR problem.
